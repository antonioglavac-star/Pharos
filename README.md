# Pharos

Logička igra sa svjetlom i ogledalima. Okreći ogledala, dijeli zraku prizmom, boji je filterima i dovedi svaki brod u luku.

## Pokretanje

Otvori `index.html` u pregledniku (dvoklik).

## Provjera razina

```
node tools/check-levels.js
```

## Rad s Claude Codeom

U ovoj mapi pokreni `claude`. Kontekst projekta i plan razvoja su u `CLAUDE.md`, pa možeš odmah tražiti npr. „dodaj razine 7–10 za otok Vis”.
